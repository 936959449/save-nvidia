替换步骤

  1. 选一个槽位，记下它的 file 路径（例：characters/jones-neutral）。
  2. 按画布尺寸作画：角色 1200×840、场景 1600×900、证据 1200×800、报纸 800×600；主体留在安全区内。
  3. 导出 PNG（源文件，透明或带底都可），命名为 jones-neutral.png 这类同名文件，放到 assets/characters/ 对应目录。
  4. 运行 python assets/tools/optimize_assets.py 生成同名 WebP；刷新页面。加载器按 webp → png → jpg → jpeg → svg 查找，WebP 会被优先加载。
  5. 要换表情，就替换 -neutral / -pressured / -pleased 三张；游戏会在选择后自动切到反应表情。
