# 拯救英伟达 · 游戏说明 v1.0

Reigns-like 竖屏卡牌游戏。双击 `index.html` 即可打开，无需启动服务。

## 怎么玩

- 按住卡片向左 / 向右拖动，松手即选择；也可用键盘 `←` / `→`。
- 点击「开始任期的第一天」会播放约 10 秒开场演出：点击画面推进；右上角「跳过开场」或 `Esc` 跳过叙事。
- 首次进入会显示「入职须知」，解释操作 / 目标 / 四条线；可跳过，之后可点游戏内「玩法 ?」重看。
- 四条线（资本 / 工程 / 客户 / 政界）任意一条触 0 或 100，任期结束。
- 底牌会在对应线归零时自动救一次（回 40），共 4 个槽位，先到先得。
- 1 张卡 = 1 周；13 张卡 = 1 个财季。没有胜利条件，只有任期天数。
- 快捷键：`R` 重开、`D` 调试数值、`?` 玩法、`Esc` 回标题。

## 内容

| 模块 | 内容 |
|---|---|
| 角色 | 7 位人物 × 3 种表情（neutral / pressured / pleased）+ 黄仁勋 3 种素材（皮衣 / 信件 / GTC 剪影） |
| 卡池 | 100 张：1 开场 + 2 里程碑 + 56 张弧线（7 条 × 8）+ 33 随机 + 8 危机 |
| 数值 | 资本 42 / 工程 55 / 客户 50 / 政界 45；两端皆死 |
| 底牌 | 现金储备、CUDA 生态、长期合约、政府订单（各救一条线一次） |
| 结局 | 8 个标准结局 + 隐藏结局「他回来了」 |
| 界面 | 桌面三栏（新闻 / 舞台 / 仪表盘）+ 手机全屏竖屏 |
| 素材 | 45 个素材槽位（全部已接入正式美术）；页面加载 WebP，PNG 为本地源/回退 |
| 引导 | 「入职须知」+ 首张卡操作提示 + 游戏内「玩法 ?」 |

## 每局差异化

- **7 条弧线**：皮衣与前任、中国市场、千亿订单、产能与供应链、华盛顿、华尔街、团队与文化。
- 开局从 7 条里**随机抽 4 条**；每条弧线独立起始回合（3–9）与推进间隔（2–4），因此同一局看不到另外 3 条，不同局的叙事顺序和内容不同。
- 33 张随机卡组成不重复袋；按 early / mid / late 阶段过滤，并做角色冷却（尽量不连续出现同一角色）。
- 8 张危机卡在任意一条线临界、或长时间无危机时优先触发；4 条线越紧张，危机越可能出现。
- 开场 c01、90 天里程碑 c09、半年里程碑 m2 固定；其余全部走随机与弧线调度。

## 资源载入与保底

- 点击「开始任期」或从首页 `?start=1` 进入时，先显示 **ASSET BUNDLE 资源载入**页：按 45 个槽位实时显示进度、百分比和当前文件。
- 载入页可以 **点击「跳过等待」或按 Esc** 跳过；跳过不会取消下载，资源继续在后台加载。
- 载入页结束后才进入开场动画；如果之前已经全部载入完成，会直接进入开场，不重复显示。
- **保底**：任何图片在解析完成前先显示 `LOADING ASSET` 占位；探测/加载失败则显示 `MISSING ASSET` 占位，并在资源到达后自动替换，不会出现破图或把上一张卡的图错误地留在下一张卡上。
- 单张图最多等待 30 秒，超时按缺失处理；用户随时可以跳过等待。

- **视觉**：8-K / INTERNAL 文件头、时间码与 90 天印章、压暗的顶层办公室空镜、最后一拍出现皮衣证据图与按钮；文字逐行 `translateY + blur` 渐显。

- **换背景/证据图**：沿用槽位 `scenes/office` 与 `evidence/jacket`，替换 `assets/` 同名 PNG 后运行 `assets/tools/optimize_assets.py` 生成 WebP。

## 新手引导

- **首次进入**：开场结束（或跳过）后显示「临时 CEO 入职须知」；解释操作、90 天里程碑、四条线参数与结束条件；可跳过，已读状态存 `localStorage`（`saveNvidia.guideSeen`）。
- **首次操作提示**：第一张卡上方出现“按住卡片拖动 · 松手确认选择”；首次选择后提示“四条线已变化 · 任一归零或爆表，任期结束”。
- **重复查看**：游戏内右上角「玩法 ?」或键盘 `?` 打开；从游戏中打开时关闭后回到当前进度，不重开。
- **位置**：`index.html` 的 `#screen-guide`；逻辑在 `game.js` 的 `openGuide` / `closeGuide` / `showCoach`。

## 美术资源

- 资源清单与预览：`assets.html`（直链，不在游戏内导航中）。
- 规范：角色 1200×840、场景 1600×900、证据 1200×800、报纸配图 800×600；安全区见清单。
- 当前 45 个槽位均已接入正式美术；新增 4 位角色与 4 个场景当前未进入 100 张卡，留给后续扩展。
- 把同名 PNG 放到 `assets/` 对应目录，然后运行 `python assets/tools/optimize_assets.py` 生成 WebP；加载器按 `webp → png → jpg → jpeg → svg` 查找。
- 清单数据：`assets/manifest.json`（可读版本）与 `assets/manifest.js`（游戏用，file:// 直接打开也不受 fetch 限制）。
- 占位图生成：`assets/tools/generate_placeholders.py`；压缩脚本：`assets/tools/optimize_assets.py`。
- 当前 PNG 61.9 MB → WebP 2.2 MB（约 3.5%）；首屏只加载 3 张图，其余在资源载入阶段预热。

## 实现

- 纯静态 HTML/CSS/JS，无构建步骤、无外部依赖；`file://` 直接打开可跑。
- 素材加载不依赖 `fetch`：清单以 JS 变量注入，图片用 `<img>` 加载并按扩展名优先解析。
- 数值只在调试模式（`D`）显示；正常界面只有刻度、临界脉冲与箭头。
- 表情切换：选择后按效果净变化自动切到 `pleased` / `pressured`，再飞卡进入下一张。
- 最佳任期存 `localStorage`（`saveNvidia.best`）。
