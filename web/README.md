# 网页视觉方案 · v1.0（PC + H5）

《拯救英伟达》的网页版视觉提案。直接双击 `index.html` 打开即可，无需启动服务。

> 游戏入口：[`game/index.html`](game/index.html)；美术资源清单：[`game/assets.html`](game/assets.html)。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 视觉方案单页：设计概念、双端界面、互动状态、交互样张、适配规则、组件规范 |
| `styles.css` | 设计变量与全部组件样式 |
| `app.js` | 样机缩放、滚动动效、可交互样张逻辑 |
| `preview-desktop.png` / `preview-mobile.png` | 桌面 1440 / 手机 390 首屏预览 |

## 视觉语言：印刷档案（Risograph Dossier）

人物与内容素材从「几何头像」升级为「印刷档案」：半调网点、套色错位、纸边剪裁、档案编号、胶带与印章。这个方向取自 DrawAI 插件的两个 MG 风格施工包：

- **06-collage 拼贴剪贴·撕纸印刷**：纸纹底、半调网点、2–4px 白剪边、胶带、档案排版（`mg_style read 06-collage`）。
- **01-flat-vector 扁平矢量**：零渐变、纯色块、有限色板、几何化人物（`mg_style read 01-flat-vector`）。

落到静态网页时，只保留可印刷的静态特征（网点、错位、剪边、档案标签），不搬 12fps 抖动等动态语法。

## 人物资产怎么改

六个 SVG symbol 定义在 `index.html` 的 `<defs>` 中，统一 `viewBox="0 0 120 84"`：

| id | 人物 | 用途 |
|---|---|---|
| `#p-jones` | 哈维·琼斯 | 首屏档案卡、人物档案卡、示例卡 |
| `#p-cfo` | 科莱特·克雷斯 | 档案卡、示例卡 |
| `#p-admin` | 玛丽 | 档案卡、示例卡 |
| `#p-reg` | 老周 | 手机端样机、档案卡、示例卡 |
| `#p-official` | 许可官 | 桌面端样机、档案卡、示例卡 |
| `#p-coat` | 皮衣 / 前任 | 证据照片、档案卡、结局卡 |

使用方式：`<svg viewBox="0 0 120 84"><use href="#p-jones"/></svg>`。
替换真实插画时保持 symbol id 不变，把内部改为 120×84 的图形即可；卡片外框会自动缩放。

卡片本身是「档案卡」结构：`FILE 编号 · 日期`、阵营色点、装裱照片、姓名/职位、台词、两个选项；红章 `TEMP CEO / 90 DAYS` 是首屏专用。

## 其他内容素材

- **人物档案**：`.cast-grid` 六张纸卡，配胶带、裁切角标与阵营色条；移动端两列。
- **报纸结局**：`.mn-*` 组件（刊头、期号、半调新闻图、任期与印章），用于交互状态与交互结局。
- **证据照片**：首屏右下角 `EVIDENCE 01 · 皮衣`，用 `#p-coat` + 胶带呈现。
- **图标**：`#i-cap`（资本）、`#i-eng`（工程）、`#i-cus`（客户）、`#i-pol`（政界）、`#i-cash`（现金储备）、`#i-doc`（长期合约）、`#i-shield`（兜底底牌）。
- **首屏组件**：终端面板 `FOUR LIVES`、档案卡、时间/财季 chip。

## 怎么改文案与数值

- 交互样张的卡片数据在 `app.js` 的 `CARDS`：`file`、`faction`、`color`、`role`、`name`、`quote`、左右选项与数值。
- 颜色、圆角、间距等变量在 `styles.css` 顶部 `:root`。
- 断点：1440 三栏 / 1024 两栏 / 768 单栏 + 桌面线框 / 390 全屏竖屏；`fitAll()` 按容器缩放样机。

## 已验证

- 1440 / 1024 / 768 / 390 四档无横向溢出、无控制台报错；
- 交互样张：选项推进、档案编号/阵营切换、撞线结局、隐藏结局「他回来了」、重新开始均正常。
